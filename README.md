# 🤖 أداة توليد توكنات Discord

أداة شاملة ومتقدمة لتوليد وإدارة توكنات Discord بطريقة آمنة وسهلة الاستخدام. تتميز بواجهة ويب حديثة وميزات قوية لإدارة التوكنات.

## ✨ الميزات

### 🔑 توليد التوكنات
- **توليد توكنات البوت**: إنشاء توكنات بوت Discord بالتنسيق الصحيح
- **توليد توكنات المستخدم**: إنشاء توكنات مستخدم بأشكال متنوعة
- **تشفير آمن**: استخدام خوارزميات تشفير قوية لحماية التوكنات
- **أسماء مخصصة**: إمكانية إعطاء أسماء مميزة للتوكنات

### 🛡️ التحقق والأمان
- **فحص التنسيق**: التحقق من صحة تنسيق التوكن
- **اختبار API**: التحقق من صلاحية التوكن مع Discord API
- **تشفير التخزين**: جميع التوكنات محفوظة بشكل مشفر
- **مفتاح تشفير تلقائي**: توليد مفتاح تشفير فريد لكل تثبيت

### 📊 إدارة التوكنات
- **عرض شامل**: قائمة بجميع التوكنات المحفوظة
- **تفاصيل كاملة**: عرض معلومات مفصلة لكل توكن
- **نسخ سريع**: نسخ التوكنات بنقرة واحدة
- **حذف آمن**: إمكانية حذف التوكنات غير المرغوب فيها

### 🎨 واجهة حديثة
- **تصميم متجاوب**: يعمل بشكل مثالي على جميع الأجهزة
- **واجهة عربية**: دعم كامل للغة العربية
- **إشعارات تفاعلية**: تنبيهات فورية للعمليات
- **تأثيرات بصرية**: انتقالات ناعمة وتصميم جذاب

## 🚀 التثبيت والتشغيل

### المتطلبات
- Python 3.7 أو أحدث
- pip (مدير حزم Python)

### خطوات التثبيت

1. **تحميل المشروع**
```bash
git clone <repository-url>
cd discord-token-generator
```

2. **تثبيت المتطلبات**
```bash
pip install -r requirements.txt
```

3. **تشغيل التطبيق**
```bash
python app.py
```

4. **فتح المتصفح**
اذهب إلى: `http://localhost:5000`

### التشغيل في الإنتاج

لتشغيل التطبيق في بيئة الإنتاج باستخدام Gunicorn:

```bash
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

## 📖 كيفية الاستخدام

### 1. توليد توكن جديد

1. اختر تبويب **"توليد توكن"**
2. أدخل اسماً مميزاً للتوكن
3. اختر نوع التوكن (بوت أو مستخدم)
4. اضغط **"توليد التوكن"**
5. انسخ التوكن المُولد واحفظه في مكان آمن

### 2. التحقق من توكن

1. اختر تبويب **"التحقق من التوكن"**
2. الصق التوكن في المربع المخصص
3. اضغط **"التحقق من التوكن"**
4. ستظهر نتائج فحص التنسيق واختبار API

### 3. إدارة التوكنات المحفوظة

1. اختر تبويب **"إدارة التوكنات"**
2. اعرض قائمة بجميع التوكنات المحفوظة
3. استخدم الأزرار للعرض، النسخ، أو الحذف

## 🔧 API المتاحة

التطبيق يوفر API RESTful للتفاعل البرمجي:

### توليد توكن
```http
POST /api/generate
Content-Type: application/json

{
    "name": "اسم التوكن",
    "type": "bot" // أو "user"
}
```

### التحقق من التوكن
```http
POST /api/validate
Content-Type: application/json

{
    "token": "TOKEN_HERE"
}
```

### الحصول على التوكنات
```http
GET /api/tokens
```

### الحصول على توكن محدد
```http
GET /api/tokens/{id}
```

### حذف توكن
```http
DELETE /api/tokens/{id}
```

## 🔒 الأمان

### تشفير البيانات
- جميع التوكنات محفوظة بشكل مشفر باستخدام مكتبة `cryptography`
- مفتاح التشفير يُنشأ تلقائياً ويُحفظ في ملف منفصل
- لا يمكن قراءة التوكنات بدون مفتاح التشفير

### أفضل الممارسات الأمنية
- لا تشارك ملف `secret.key` مع أحد
- احتفظ بنسخة احتياطية من مفتاح التشفير
- استخدم HTTPS في بيئة الإنتاج
- قم بتحديث المكتبات بانتظام

## 🛠️ التخصيص

### تعديل التصميم
يمكنك تخصيص مظهر التطبيق عبر تعديل ملفات CSS في مجلد `static/css/`

### إضافة ميزات جديدة
التطبيق مصمم بطريقة قابلة للتوسع، يمكنك إضافة ميزات جديدة عبر:
1. إضافة routes جديدة في `app.py`
2. تحديث واجهة المستخدم في `templates/index.html`
3. إضافة وظائف JavaScript في `static/js/script.js`
